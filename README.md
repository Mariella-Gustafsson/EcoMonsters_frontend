# Frontend till spelet om återvinning: ECO MONSTERS

Detta är frontend för ett spel om återvinning.  
Byggt med **Vite**, **React** och **TypeScript**.

---

**Backend**

Frontend kommunicerar med en Express-backend för att hantera data och serverlogik.

GitHub-repo för backend: https://github.com/Mariella-Gustafsson/EcoMonsters_Backend

**Design**

Visuella UI-element såsom bakgrund, föremål och monster är genererade med AI-verktyg (Craiyon och ChatGPT) och sedan implementerade och anpassade i React.

**Funktioner**

- Drag-and-drop spelmekanik
- Dynamisk UI uppdatering
- Komponentbaserad struktur
- API-kommunikation med backend

# Kom igång

## 1. Klona repot

```bash
git clone https://github.com/Mariella-Gustafsson/EcoMonsters_frontend.git
```

## 2. Installera dependencies

```bash
npm install
```

## 3. Starta servern

```bash
npm run dev
```

Frontend körs i nuläget på port **3000**.
